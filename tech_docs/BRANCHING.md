# Стратегия ветвления

## Основные ветки

- **master** — ветка для получения актуальных обновлений.
- **techpeople_master** — основная ветка компании. В неё мерджится только проверенный код.

## Процесс работы

1. Под все фичи и задачи создаются отдельные ветки.
2. После тестов, если всё в порядке, ветки вливаются в `techpeople_master`.
